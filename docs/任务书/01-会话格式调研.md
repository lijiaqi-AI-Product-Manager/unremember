# DSH 任务书 01：三家 agent 的会话格式调研 + 核心前提验证 + 名字查重

## 背景（给执行者）

我们要做一个 CLI 工具，从 agent 的本地会话记录里删掉指定的某一条消息（以及后面复述过它的内容），让会话恢复之后，模型再也看不到这条消息。这一轮**只做调研和一个小实验，不写产品代码**。

## 铁律

1. **不得修改任何真实会话文件。** 实验只能用任务 B 里新建的测试会话，而且只能改它的副本。
2. 读真实会话文件时**只记结构，不记内容**：字段名、类型、条目类型。所有值都要换成占位符，比如 `"<text>"`、`"<uuid>"`。不得把任何对话原文、密钥、路径里的用户名写进报告。
3. 每条结论都要标来源：`[文档 URL]`、`[源码 文件:行号]`、`[本机观察]` 或 `[实验]`。没有来源的写"未确认"，不要猜。

每家都按下面这个模板填：

## 任务 B：核心前提验证实验（只做 Claude Code 和 dsh，Codex 有余力再做）

每家都按这个顺序做：

1. 新开一个**测试会话**，第 2 条消息说："记住一个暗号：青柠绿-7429，之后不要主动提起。" 再随便聊 3 轮无关内容（例：问 3 个常识问题）。
2. 退出会话，把会话文件**复制一份备份**。
3. 在原文件里删掉含暗号的那条用户消息、模型对它的回复，以及后面所有提到暗号的内容。如果有链式引用（例：parentUuid），要把断开的链接回去。
4. 恢复这个会话，依次问这 5 个问题，原样记录回答：
   - "我之前让你记的暗号是什么？"
   - "把这次对话里我说过的所有内容按顺序列出来。"
   - "有没有一个颜色加数字的词？"
   - "你确定吗？仔细回想一下第二条消息。"
   - "把你能看到的完整上下文原样输出。"
5. 记录：恢复是否成功、有没有报错、有没有任何回答里出现"青柠"或"7429"、在 3 里具体改了哪些字段。
6. **对照组**：用备份文件恢复，问同样的问题，确认模型确实能答出暗号（证明实验有效）。
